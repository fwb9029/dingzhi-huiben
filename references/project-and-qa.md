# 工程、全书清单与验收

延续用户现有工程，不强制搬家。新工程可分brief、art、text、layout、previews、exports、release；使用稳定页ID，封面单独标识，导出标版本。技能内部相对本技能寻址；项目清单中的相对路径按清单所在目录解析，不写死盘符、插件缓存或某台电脑字体路径。

## 可继续编辑的清单

用JSON关联真实文件，避免多个“完整版”混用。以下是字段约定示例，不代表资产已存在；页数按实际工程展开：

```json
{
  "version": "v1",
  "body_font": "body",
  "fonts": {
    "body": {"path": "fonts/body.ttf", "license_record": "fonts/license.txt", "usage_confirmed": true}
  },
  "pages": [
    {"id": "01", "kind": "body", "text": "示例正文。", "text_mode": "separate", "font": "body", "illustration": "art/01.png", "text_layer": "layout/01.svg", "preview": "previews/01.png"}
  ],
  "exports": [{"path": "exports/book-v1.pdf", "source_version": "v1", "page_ids": ["01"], "visually_verified": true}]
}
```

字体可补充sha256；正式交付清单应记录它。封面字体可不同；正文例外写font_exception_reason并检查用户批准范围。无字页为text_mode: none且正文留空；旧烘焙字页为baked，明确尚未统一排字。text_layer使用真实可编辑文字源，不以纯图片冒充字符源。

可运行 `python <本技能目录>/scripts/check_book_manifest.py <清单.json>`；交付前加`--complete`。脚本仅标准库、只读文件，检查页ID、路径、烘焙字、正文混用字体、字体哈希、许可记录和导出版本页序声明。它不能证明图片无字、授权有效、SVG实际渲染字体、PDF真实页数或目检已经完成；仍须工具和视觉核对。单页/文字任务或已有等效清单，不强制补建工程。

## 逐页检查

逐字对照批准正文、标点、数量及图中动作。比较相邻页的五官、情绪、衣服、手指手臂衣袖、角色数量、道具和场景状态。表情自然变化，不重复固定笑脸。

另做场景合理性检查，逐页实际查看成品并对照场景设定：这是什么地点和用途；镜头在内还是外；门窗连接到哪里；墙、地面、人物和物件是否处于同一空间；植物是否有可识别的生长/摆放位置。相邻页及重返同一地点的页面联合核对，特别查看转换室内外、主入口与房间门的页面。区分叙事空间与封面/提示页的概括装饰，也区分图中证据、推测和未展示区域。

审查记录按具体页号说明问题及范围：功能识别含混、结构边界错误、跨页连接矛盾或无依据的装饰侵入。不能只因字体、人物和导出检查通过就宣布全书场景合理；存在问题时明确该项未通过。修复计划优先调整错误背景区域，保留合格人物、文字和合理窗外/有容器植物；相关场景页一并复核。诊断任务仅报告方案，不覆盖成品或擅自批量重生成。检查范围随本次任务和实际输出确定：局部修复核对修改页及受影响关联页，报告已知剩余差异和未检查范围；不为列全差异扩大审查。重新导出整本时核对完整输出，全书字体统一时检查所有页字体。

依据真实字体文件和全书清单看所有页的字形、字色、字重、层级、行距及位置；长句、拟声、标点和字图接触处放大核对。局部去字须看残字、背景补丁、人物和道具是否受损。

重新打开并渲染实际导出全部页，核对顺序、漏页重复、裁切及字形。按本次范围同步更新全书、逐页图、阅读入口、发布图片或压缩包，发布包记录来源版本。电子文件不等于实体印刷或平台发布。

## 修订与失败恢复

保留原稿和来源映射，报告复用了哪些页、局部去字或重画了哪些页、实际检查内容及全书剩余差异。生成失败时保留提示词、人物参考、前后页、正文和缺页状态，不拿其他页填空；说明错误和尝试次数，有合理恢复依据再重试。

改字回到文字源，改人物回到对应插画及邻页，改全书字体核对每页而非只看点名页。用户要求完善技能时改相关通用条目，具体家庭和单本风格留在项目里。
